# 분류별 웹 연구 요약 검증

검증일: 2026-10-19. 새 모델 호출·토론·재개·자료 전송 없이 수행했다.

## 구현

- 기존 로컬 제어판에 별도 전체 너비 요약 보기 추가
- 전체 현황 / AI별 조사 / 토론·반박 / 대안 C·결론 / 근거·오류·교수 비판으로 분류
- 기존 JSON 필드를 브라우저에서 재분류하며, 새 요약 생성 API를 사용하지 않음
- 전체 분석, 원질문·원답변, 입장 변경, 제안별 채택·기각·보류와 이유, 미해결 쟁점 조회
- 단계별 진행 및 참가자별 의견, 실시간 임시 응답과 중단 초안 구분
- 교정 제안과 실제 교정 재응답, 모델의 확인 주장과 독립 확인 상태 구분
- 기존 문서 9종은 웹에서 제목·목록·표로 표시하며 원본 다운로드 유지
- 현재 서버의 정적 파일 경로를 재사용하므로 서버 재시작·실행 중단 불필요

- `py -3 -m unittest test_debate test_engine_ui test_ui_server`: 24개 통과. 모델 호출을 모킹하고 임시 폴더만 사용.
- `node test_summary_contract.js`: 17개 통과. AI·HTTP 호출 0회. 동일 공급자/이름 참가자 분리, 미실행 단계, 잠정/최종 구분, 출처 상태, 실제 교정 기록, 잘못된 데이터, 원문 보존, 안전한 Markdown, 중복 완료 집계 검사.
- `node test_controller_summary.js`: 읽기 전용 GET 경로, 자동 실행 없음, 입력 설정 보존, 두 실행 선택기 동기화, 상세 JSON 병합, 캐시·수동 갱신, 빈 상태 통과.
- `node --check web/app.js`: 통과.

## 브라우저 확인

실제 저장된 연구 기록을 열어 1/18 완료, 주장 8건, 독립 조사 1/3명 및 이후 단계 미실행을 확인했다. AI별 조사 필터, A/B 비교표, 전체 분석, 발언 원문 대화창, 토론·입장 변화, 채택/기각/보류, 잠정 결론, 근거 표, 오류 후보 0건, 교수 비판 미실행을 확인했다. 관련 문서 버튼이 AI 활용 부록을 웹 형식으로 여는 것을 확인했다. 설정의 자료 12개 선택을 복원했고 전송 동의는 체크하지 않았다.
